# Tetris 🏴☠️

A swashbuckling Tetris variant with pirate-themed mechanics, ranks, and special events. Playable directly in the browser at the-architect-0.github.io/Tetris.

## Overview

Arrange falling treasure pieces before the sea claims them. Clear planks (lines) to collect booty and rise through pirate ranks. The game features classic Tetris controls with pirate-themed enhancements and a high score leaderboard.

## Core Features

· Progression System: Ranks from Powder Monkey upward with a "Next Rank" score threshold

· Hold Mechanic: Store one piece for later use with the 'C' key

· Lookout's Spyglass: Preview of the next piece

· Captain's Log: Persistent high scores tracking top pirates

· Special Events: Mentions of "Cannon Blasts" and "Parrot Assistants" (implementation details not visible)
